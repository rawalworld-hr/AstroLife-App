# AstroLife Android App

A native Android version of the AstroLife super-app concept.

Included now:
- Home screen
- Search
- Astrology
- Events
- Decoration
- Catering
- Consultancy
- Tours & Travel
- Online Shopping
- Service detail pages
- Bottom navigation
- Booking/quotation interaction placeholders
- Bookings and profile placeholders
- English / Gujarati / Hindi / French language indicator

## Automatic APK build
GitHub Actions builds a debug APK from the Android project. Open the Actions tab, select **Build AstroLife APK**, then download the **AstroLife-APK** artifact from a successful run.
